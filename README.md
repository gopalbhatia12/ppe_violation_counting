# PPE Violation Detection and People Counting

A Streamlit application that processes uploaded videos, detects people and PPE, tracks people across frames, summarizes PPE observations, and optionally emails a CSV report.

## Features

- Upload MP4, AVI, MOV, or MKV videos.
- Detect people and PPE using an Ultralytics YOLO model.
- Track people between frames with ByteTrack.
- Classify helmet and vest observations as `Safe`, `Violation`, or `Needs Review`.
- View people-counting metrics and the PPE observation table.
- Download an annotated H.264 video and CSV report.
- Email the report as a CSV attachment through an SMTP server (Gmail by default).

## Requirements

- Python and pip
- A compatible YOLO weights file at `models/best.pt`
- Packages listed in `requirements.txt`
- PyTorch, torchvision, Polars, and NetworkX: these are imported by the application but are not currently listed in `requirements.txt`. Install compatible versions for your Python and hardware; use the [official PyTorch installation selector](https://pytorch.org/get-started/locally/) for PyTorch and torchvision.

The model must recognize the class names `person`, `helmet`, `no_helmet`, `vest`, and `no_vest` for all of the application's detection and PPE checks to work as intended.

## Installation

From the project directory, create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows PowerShell, activate it with:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the listed packages and the additional dependencies above:

```bash
pip install -r requirements.txt
pip install polars networkx
```

Install PyTorch and torchvision using the command generated by the official PyTorch installation selector, then verify the model file exists at `models/best.pt`.

## Run the application

```bash
streamlit run ppe_app.py
```

Open the local URL printed by Streamlit, upload a video, and select **Start Detection**. When processing completes, the results and **Send Report via Email** control appear on the page.

## Email configuration

The application accepts SMTP credentials from environment variables (including a project `.env` file) or from `.streamlit/secrets.toml`. Environment variables take precedence. Do not commit credentials.

### Using `.env`

Copy the example file and edit the values:

```bash
cp .env.example .env
```

Set `SMTP_EMAIL` and `SMTP_PASSWORD` in `.env`. For Gmail, use a Google App Password rather than your regular account password. The default SMTP server is `smtp.gmail.com` on port `587` with STARTTLS. `SMTP_HOST` and `SMTP_PORT` can be set to use another SMTP service.

### Using Streamlit secrets

Create `.streamlit/secrets.toml` with:

```toml
SMTP_EMAIL = "your-email@example.com"
SMTP_PASSWORD = "your-app-password"
SMTP_HOST = "smtp.gmail.com"
SMTP_PORT = "587"
```

Keep this file private; it is excluded by `.gitignore`.

## Generated files

Video processing writes these files into `outputs/`:

- `annotated_video.mp4` — annotated output video
- `ppe_report.csv` — one row per tracked person observation, with frame number, person ID, helmet status, vest status, and overall status

The report summary counts `Violation`, `Compliant`, and `Needs Review` observations.

## Troubleshooting

- **Model file not found:** place the YOLO weights at `models/best.pt`.
- **Video cannot be opened:** try a supported video format and confirm the file is readable.
- **Email credentials missing:** check `SMTP_EMAIL` and `SMTP_PASSWORD` in `.env` or `.streamlit/secrets.toml`, then restart Streamlit after changing configuration.
- **Gmail authentication fails:** use an App Password, ensure two-step verification is enabled, and check that the sender account is correct.
- **Email sending fails:** the app displays the SMTP exception in the UI. Check network access to the configured SMTP host and port as well as the credentials.
